## Changes and privacy decisions

1. **Web background generation:** document visibility immediately advances selected/list generations, aborts tracked commands, disposes the history owner and clears fetched lists, metadata, people and bodies. Pre-background metadata, history/sync, older-page, list and command completions cannot publish. Foreground creates a fresh authorization generation and restores the authorized oldest range from content-free position metadata; authored scoped RAM remains. Commands recheck ownership again after their refresh lane finishes.
2. **Unloaded and pending sources:** changed IDs are exposed independently of loaded message rows. Every affected source panel/quote is cleared; target/thread reads use request tokens and pending-source identity. Search/saved components remount on source changes. Per-ID revision stamps let a freshly reauthorized source remain open when an unrelated history publication occurs; old accumulated IDs are not reapplied as new invalidations. Native history owners and target loads also bind current root/foreground/client generation and request identity. A late native send cannot merge into a replacement history owner.
3. **Contextual deleted-root404:** only the exact message-thread read may classify404 as contextual, and only after a fresh conversation metadata read succeeds. The source is scrubbed; replay reconciles authorized pages and drains later event pages. Denied metadata still invokes fail-closed401/403/404 cleanup. Shared history emits invalidations before hydration, and incorporates authorized incoming thread replies. No blanket native404 suppression was introduced.
4. **Native delayed foreground:** background invalidates session-restore sequence and client generation. Active return chains session restore → fresh company refresh → Android pending camera recovery. Deferred/late restores cannot authorize a background or replacement scope. The company refresh rechecks the full membership fingerprint before redisplaying RAM input.
5. **Native anchor:** persisted offset is canonical row top relative to viewport, not absolute scrollTop. A stable FlatList CellRenderer adapter measures content-relative row top/height. Restoration uses the current measured position minus saved relative offset; unmeasured anchors wait/use index positioning, and measurement corrects the position. No fabricated getItemLayout. Changed wrapped heights above the anchor are covered by pure-model and component callbacks; native physical pixels remain unchecked.
6. **Matching confirmed forms:** useRamInput subscribes to canonical RAM ownership and exposes compare-and-retire/match callbacks. Confirmed Publication clears the matching pending attempt and authored fields/key before refresh, permitting a new unlocked publication on reopen. Ambiguous failure retains the exact request/key. Confirmed Work clears only a fully matching submitted form; an older unmounted completion cannot close a newer authored form. Publication audience previews bind source/revision/version/root and request identity. Existing finance/evidence/review/version controls remain.
7. **Real timed Intake:** date, wall time and explicit instant are scoped RAM inputs keyed by request ID. workDeadline derives company-zone timed/all-day payloads; a fold requires choosing an ISO instant, and a gap disables assignment. Fetched request content is freshly loaded rather than retained in RAM. Assign/close completions guard target/generation; success retires matching fields.
8. **Canonical neutral source:** shared/communication/history.ts and drafts.ts own the logic. Platform files re-export it. Shared history.cases.ts/drafts.cases.ts register neutral cases for both platform runners, while mounted adapters/provider/route tests stay local. Vite permits the shared path, Expo Metro watches it, and Docker's web stage copies shared/ into /src/shared; .dockerignore permits it. Docker stage, TypeScript and both Expo bundles resolve the same source.

One amended real-browser run exposed misleading unsent quote feedback: an ordinary changed quote was labelled a frozen ambiguous send, making the reduced viewport composer overflow. The focused regression now distinguishes ordinary source-change feedback from the pending frozen-send warning; browser geometry passes at520px. Frozen pending payloads retain their original reply/mention/client ID exactly.
