# Publication privacy and reference decisions

Only the explicit whitelist in reference-closure.json was selected from named source/check/evidence/native freeze indexes and named full reports/reviews/controller proofs. No directory was copied wholesale. Original/frozen local files were read and never rewritten or deleted.

Published source-file, compiled-artifact, model/provider pin and evidence-artifact SHA values establish provenance; they are not private request/body fingerprints. A frozen build index does not publish its binary. Private canonical request/key/body equality remains a boolean observed in bounded RAM; no request/body digest is published.

Original paths are historical identifiers. Resolve each original path together with its artifact SHA through the closure; the `destination` is relative to this directory and has independently recorded `publishedSHA256` and `publishedBytes`. Exact originals retain identical bytes. Sanitized derivatives retain original artifact SHA as provenance only and have their own hash; they do not certify byte-equivalence. Excluded records remain local historical references, not broken promises of downloadable originals.

Excluded: all raw UI XML/screenshots/audio/build binaries; runtime fixture identity/control JSON and raw application runtime/fixture logs; private databases/keyrings/environment/auth/cookies/bodies/prompts/model/source prose/provider stderr; unfiltered controller progress and broad historical observation extract. The current ruling extract is complete and verbatim. Historical indexes can refer to excluded artifacts; that is an explicit privacy boundary, not an omission concealed as complete publication.

Known fictional human-authored titles and source-free controls/geometry in safe observations remain where they explain lifetime behavior. Runtime job/business/source identifiers are removed from the derivatives below. Synthetic test DOM dumps are removed while failure assertions, status/counts and owning source references remain. Schema source files, test names, public package/provider identities, templated paths and ordinary source/artifact hashes remain.

No private-identifier/hash values are recorded in this decision log. Actual fixture identities used for redaction were read and compared in RAM only. The publication audit checks JSON validity, narrow credential patterns, raw UI markers, opaque runtime IDs, sensitive body-digest keys, declared derivative hashes, path reachability and plan/ruling/source equivalence. Such scanning supplements the scoped whitelist and full report review; it is not a claim that a regex proves privacy.
