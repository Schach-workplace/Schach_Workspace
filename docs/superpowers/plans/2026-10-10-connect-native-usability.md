# Milestone 3: Connect and native usability implementation and acceptance

> **For agentic workers:** Use superpowers:executing-plans or the controller's already selected execution workflow to implement these tasks in order. The controller uses the roadmap subagent-driven workflow. Completion is recorded only in the reviewed release evidence; unchecked physical gates do not count as local acceptance.

**Goal:** Keep authorized loaded conversations stable, retain isolated unsent input, make conversation attention actionable, and improve native Work capture and navigation.

**Architecture:** Keep Go/GORM/PostgreSQL and the existing communication APIs. Stream frames are invalidation hints; the clients read authorized changes through `/sync`, then fetch projected message roots or reconcile the loaded range. Milestone 2 owns bootstrap/list/detail read models and their invalidation; this milestone consumes them rather than reintroducing `/workspace` polling.

**Tech stack:** React web, Expo `~57.0.27`, React Native `0.86.3`, Expo Router `~57.0.25`, existing Vitest/happy-dom tests, native `FlatList`, Expo-compatible date picker and image picker.

**Spec:** `docs/superpowers/specs/2026-10-10-workspace-improvements.md`; roadmap scope is exclusively milestone 3 in `docs/superpowers/plans/2026-10-10-workspace-improvements-roadmap.md`.
