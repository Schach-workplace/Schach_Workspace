# Selected-source local assistance

Local assistance is optional. Operators must provision the pinned local providers before enabling it; the application never installs a model, pulls an image, uses a remote model or falls back to a cloud service. Opening a conversation or report performs no inference. Users select readable sources, inspect their current bindings, and explicitly consent to local processing for each generation.

Set `INTELLIGENCE_ENABLED=true`, an absolute owner-only `INTELLIGENCE_SCRATCH_ROOT` (0700), `INTELLIGENCE_PYTHON`, `INTELLIGENCE_WHISPER_SCRIPT`, `INTELLIGENCE_WHISPER_MODEL`, and a literal loopback HTTP `INTELLIGENCE_OLLAMA_URL`. `backend/tools/whisper_transcribe.py --verify` checks installed Python packages and all four model-file hashes before availability is advertised. Missing executables, models, identity mismatch or incomplete configuration leave normal application workflows available and local assistance unavailable. The standalone and Encore adapters configure the same platform worker and join it during shutdown.

The accepted adapter pins are Python 3.14.7, faster-whisper 1.2.1, PyAV 18.1.0, ctranslate2 4.8.2, huggingface_hub 2.2.0 and Whisper tiny revision `d90ca5fe260221311c53c58e660288d3deb8d356`; the script contains the complete model checksums. Ollama 0.40.2 must expose local `qwen3:4b` digest `359d7dd4bcdab3d86b87d73ac27966f4dbb9f5efdfcc75d34a8764a09474fae7`. The HTTP adapter disables environment proxies and redirects, verifies version/model metadata before sending selected content, and rejects remote/cloud descriptors. It uses no tools, retrieval URLs or model-provided paths.

The Ollama request fixes context 8192, accepted input at most 6144 actual tokens, output at most 1024 tokens, temperature 0, seed 1, and `stream`, `think`, `truncate`, and `shift` false. The prompt requests at most three concise items, but schema validation remains independent. Overflow is terminal `source_too_large`: users must reselect sources or continue manually. There is no automatic truncation, chunking, source removal or context reduction. Actual model token counts are checked; character counts are not presented as token counts. These ceilings are limits, not throughput or latency guarantees.

Each job permits at most 50 selected sources, 1000 expanded roots, 64 KiB and 20,000 Unicode scalars of selected content. Voice requires exactly one clean, attached WAV/M4A/WebM, at most 25 MiB and 600 seconds. The worker hashes media bytes, performs bounded audio-only probing, rejects video, and decodes to bounded mono PCM. Whisper runs offline on CPU/int8 with four threads, one worker, beam size 5 and VAD disabled. Scratch directories and files are 0700/0600; cancellation closes readers, terminates and joins the subprocess group, and deletes temporary files. Maintenance only sweeps aged directories with this worker's job/lease marker, never active leases or symlink targets.

A separate worker claims one job only after acquiring `Options.LocalProviderBudget`, the same instance used by OCR. Inference holds no database transaction. Claims use short transactions and lease tokens; cancellation, original-session authority, current membership and every selected root are checked again before disclosure and before the final atomic commit. Lease renewal never extends the invocation deadline: 120 seconds for Ollama and 180 seconds for transcription. Transient retries are bounded to three attempts with 5/30-second delays. Maintenance runs independently every 60 seconds in batches of 100. Deploy only one worker process against a provider-capacity domain; multiple processes require a shared capacity lease or workers disabled on the other replicas. An in-process semaphore is not a distributed capacity guarantee.

Raw result lifetime is the minimum of 24 hours and every selected source's effective retention/capability expiry, including parent transcript expiry. Task due dates are not expiry. Cancel, invalidation and expiry scrub result bytes. Durable jobs and publication provenance retain only identifiers, hashes, schema/lease/status metadata and minimal authorization bindings for canonical retries; they never retain source prose in the manifest. Those metadata rows remain until the owning company/database lifecycle removes them. Changing login or leaving and rejoining a private interval cannot revive an old raw handle. Current reads check all sources before loading result JSON; owner history contains only neutral operation/status metadata.

Generated suggestions create no business records until a human resolves the required owner, independent reviewer, deadline and, where applicable, exact monetary/destination fields, previews the complete current audience and confirms. A private selection spanning conversations is read-only. Published tasks, expense drafts and intake requests use the existing canonical mutation engines. First writes validate the exact ready result inside the business transaction. Replays use current source/destination ACL and minimal publication provenance independently of raw-result expiry. The publication-access route authorizes an unknown frozen attempt without rereading expired prose. The original request key and body remain frozen in the existing scoped RAM registry; there is no second attempt store or persisted result cache.

Citations indicate provenance, not factual correctness. Report explanations select allowlisted fact keys and relations; server templates render exact recorded finance/report/goal/planning values. They cannot alter money, approve expenses or update goal observations. Model prose is rendered as text and has no automatic link, tool, share or download execution.

Acceptance uses public English speech and fictional business data. Physical mobile microphone/keyboard/accessibility/background behavior, signing, iOS devices, language accuracy, unsupported-claim evaluation, production latency/capacity, wheel/base-image supply-chain completeness, India TLS/TURN and disaster recovery remain separate rollout gates. One successful fixture does not certify them.
