Source decisions and limits:

- DM creation omits a name and uses server pair reuse even beyond a loaded list page. Named groups/channels retain name requirements. Public company channels expose retained history to active company members; private join/rejoin uses forward history intervals. No typing/presence UI or per-person read receipt was found in the inspected current Connect/native source; these are excluded rather than invented.
- Structured acknowledgements/polls/events/decisions use fixed revision-bound recipients intersected with current source access. Independent decision response never approves a task or payment. Optional blank deadline remains blank. Split work actions are explicit server IDs; primary A versus A+B claims reuse original work. Intake triage retains task versions, assignment authority and independent review.
- Task conversion seeds its title from selected message text. That title is a disclosure even with excerpt unchecked; the case requires reviewing both title and optional exact excerpt plus current broader audience. Already published work/evidence remains independent after source withdrawal. Accepted canonical replay can return an existing result after current access checks; it must not substitute new source prose. Fresh actions still require current source revision.
- Media scanning is fail closed. A scan error changes uploaded media to rejected; the catalog does not claim that retrying finalize makes that reservation clean. Clean attached-audio opt-in assistance is a separate LOCAL_CONFIG flow; live-call recording/transcription stays disabled. Expired bytes are denied before asynchronous cleanup; restored backups require retention reapplication but no restore is executed or historical native fixture revived here.
- Chat download currently performs `io.Copy` within `withCommunicationTransaction`. It has current session/company/source/history/expiry/clean checks, but the catalog does not borrow report CSV per-chunk fencing or promise revoke interruption during a slow transfer. Revocation may wait for that transaction; already sent/in-flight bytes cannot be recalled. Native downloads remove owned temporary cache after OS sharing returns; deliberate external shared copies remain an explicit exception.
- Calling requires self-hosted LiveKit and revocable Schach signaling; actual signaling joins distinguish answered from missed, and immutable grants protect authorized rejoin from delayed old cleanup. Foreground active-call lists are implemented. Token success does not prove media; OS incoming screens/background push/headsets/lock/network behavior remain DEVICE. Trusted TLS, private provider ingress and authenticated TURN on named staged India infrastructure remain PRODUCTION.
- Native phone keyboard/enlarged text/focus/Back/44dp target cases are DEVICE, not browser CSS-pixel claims. Scoped authored RAM may survive same-company navigation/temporary background; fetched private views stay withheld until fresh foreground authorization. Confirmed account/origin/company/history/source boundaries clear affected input/captures. Process death loses RAM drafts; secure session storage and owned temporary media files are explicit different mechanisms.

Cases must run only against newly owned fictional isolated fixtures, qualified exact-source native builds or the named staged deployment. Missing prerequisites are BLOCKED; historical automated logs, browser demo, exports and earlier APKs are not newly authored manual passes. Keep only sanitized team evidence; do not retain raw private UI screenshots, copied model output, token traces or provider credentials.
