Review these boundaries independently:

- [ ] Company and private-source isolation; revocation/rejoin and current reads.
- [ ] Independent task/decision/finance review; exact amounts and original deadlines.
- [ ] Unknown-ACK exact canonical retry and intentional conflict recovery.
- [ ] Public report delivery; original snapshot/source/recipient/stream controls.
- [ ] Mobile keyboard/focus/Back/enlarged text and authenticated signed release.
- [ ] Configured provider failures, grounded output review and cancellation.
- [ ] India TLS/network, LiveKit/TURN and real background APNS/FCM delivery.
- [ ] Coordinated database/media/key backup and measured restore/RPO/RTO.
- [ ] Representative language/domain accuracy and production capacity.

Record an owner and explicit reason for every open external gate. Local
implementation acceptance does not imply production release approval.
